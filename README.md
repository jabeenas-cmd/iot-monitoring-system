# Industrial Machine Monitoring with Digital Twin

## Overview
This project focuses on industrial machine monitoring using IoT and Digital Twin concepts. The system is designed to collect machine data, transmit it through IoT communication channels, and create a virtual representation of the machine for monitoring and analysis.

## Objectives
- Real-time machine monitoring
- Remote data collection
- Digital Twin representation
- Predictive maintenance support

## Technologies
- STM32
- ESP32
- Embedded C
- UART DMA
- MQTT
- JSON
- IoT Communication
